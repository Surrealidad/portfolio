Game + Telemetry

K&G Go for a Stroll

A browser endless runner that ships as a single self-contained HTML file, no build step and no dependencies. Every run reports anonymous telemetry to a Sheets backend, and a static analytics site rebuilds on top of it every six hours, published live alongside the game.

The analysis is built to resist its own convenient conclusions. Survival curves show where runs end, with the hazard estimate cut off once too few runs remain to support it. Every behavioural feature is a per-metre rate or a pure ratio, so nothing scores well merely for lasting longer, and an explicit check reports how much each rate is really just a proxy for run length. Death cause by platform is tested with chi-square, control use with a two-proportion test, and k-means separates playstyles. Each panel writes its own verdict from its own result, gated on significance and a minimum effect size so a trivially small finding is not oversold.
